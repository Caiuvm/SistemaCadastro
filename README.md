# SistemaCadastro

## 1. Qual a finalidade de uma branch?
     O branch permite o desenvolvimento de funcionalidades sem afetar a versão principal do sistema.
   
## 2. Qual a diferença entre commit e merge?
    O commit salva as alterações locais no projeto enquanto o merge junta as alterações feita por vários usuários.

## 3. Por que é importante utilizar mensagens claras nos commits?
     Porque com mensagens claras, dá para entender melhor a mudança que foi feita naquela commit.
   
## 4. Por que o controle de versão é importante em equipes de desenvolvimento?
    É importante pois caso seja lançada uma próxima versão que apresente problemas, a equipe pode voltar na versão que estava funcionando 100%.
   
## 5. O que representa a versão 1.1.0 no contexto desta atividade?
    Representa a versão do sistema após a inclusão da nova funcionalidade.
   
## 6. A tag foi criada direto na interface do GitHub, essa tag também pode ser realizada pela interface CLI,
escreva abaixo os comandos git para criação desta tag.
  git tag -a v1.1.0 -m "versão 1.1.0 com a nova funcionalidade"
